Issue 01
19–26 Sep 2026
18 picks · 6 columns

This week the theme was efficiency: same answers for fewer tokens, big models squeezed onto laptops, and agents that improve their own harnesses without overfitting. Tap any card for a plain-language explanation. The section at the bottom explains the older ideas these works build on.

Also shipped this week

  • Speck1-140M (Speck Labs, this week on Hugging Face): a 140.7M-parameter base model trained from scratch on 5B tokens in about 25 hours. It mixes attention with gated convolution layers. MIT licence, not instruction-tuned.
  • Grok 4.7 (xAI, 21 Sep): new larger base model, $2 / $6 per million tokens, 500K context. Every benchmark in the launch table was run by xAI itself.
  • Qwen3.8-Omni-Flash (Alibaba, 18 Sep): takes text, image, audio and video in, 1M context, $0.15 / $0.47. API only.
  • FLUX 3 Action (Black Forest Labs, 23 Sep): open 7B "world action model" for robot control, built from an image-generation backbone.
  • Gemini 3.8 Flash TTS (Google, 22 Sep): speech models with voice replication. The promotional price doubles on 1 Jan 2027.

Where these ideas come from

Most of this week's work adds to a few older ideas. Each entry says what the idea is, where it first appeared, and how this week's work uses it. cited means the new work names this source directly. background means it is the standard origin of the technique the new work uses.

Sources scanned for this issue: Hugging Face trending papers and blog, arXiv abstract pages, vendor announcements, and the Digital Applied September release ledger (which checks each release against the vendor's own page).
Most numbers here were measured by the vendor or the authors themselves. Cards say so where it matters. Treat a benchmark score as a claim until someone independent repeats it.
