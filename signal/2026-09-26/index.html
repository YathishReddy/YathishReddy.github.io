18 picks · 6 columns

This week's theme is efficiency: the same answers for fewer tokens, large models compressed onto laptops, and agents that improve their own harnesses without overfitting.

The week at a glance

    Also shipped this week

    • Speck1-140M (Speck Labs, this week on Hugging Face): a 140.7M-parameter base model trained from scratch on 5B tokens in about 25 hours. It mixes attention with gated convolution layers. MIT licence, not instruction-tuned.
    • Grok 4.7 (xAI, 21 Sep): new larger base model, $2 / $6 per million tokens, 500K context. Every benchmark in the launch table was run by xAI itself.
    • Qwen3.8-Omni-Flash (Alibaba, 18 Sep): takes text, image, audio and video in, 1M context, $0.15 / $0.47. API only.
    • FLUX 3 Action (Black Forest Labs, 23 Sep): open 7B "world action model" for robot control, built from an image-generation backbone.
    • Gemini 3.8 Flash TTS (Google, 22 Sep): speech models with voice replication. The promotional price doubles on 1 Jan 2027.

    Where these ideas come from

    Most of this week's work builds on a small number of earlier ideas. Each entry explains the idea, where it first appeared and how this week's work uses it. cited means the new work names the source directly; background means it is the standard origin of the technique used.
