Signal Weekly

Issue 02
27 Sep – 3 Oct 2026
18 picks · 6 columns

This week's theme is putting work in the right place: prompt reading and answer writing on separate hardware or in separate number formats, cached prompts reused on phone chips, and context that the model edits itself. Google, Anthropic and OpenAI also shipped new frontier, mid-size and agent products.

    Also shipped this week

    • GPT-6.1 Sol ↗ (OpenAI, 29 Sep): an upgrade to the mid-size GPT-6 Sol at the same $2 / $10 per million tokens, with cached input at $0.10. OpenAI describes it as near-Astra performance at a fifth of the price; the comparison is OpenAI's own.
    • Perplexity Decisions API ↗ (Perplexity, 1 Oct): a "decision model", pplx-decider-v1-27b, that returns yes/no, multiple-choice or rubric answers instead of free text. Input costs $0.04 per million tokens, output is free, and requests can be up to 262,144 tokens.
    • Decision models in llama.cpp ↗ (ggml-org, 2 Oct): a new /v1/systemone server endpoint scores a fixed set of options in one forward pass instead of generating text. Five open models from 144M to 27B parameters are supported, for routing, moderation and agent action selection.
    • NVIDIA cuObject and SCADA Server SDK ↗ (NVIDIA, 30 Sep): cuObject libraries for GPU access to object storage are now generally available, and a new SDK lets storage vendors build servers that answer GPU-initiated requests.
