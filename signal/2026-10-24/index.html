Signal Weekly

Issue 05
18 – 24 Oct 2026
18 picks · 6 columns

This week open models closed in and agents learned to ask first. Moonshot's Kimi K3.1 Pro comes within a point of Claude Opus 5.5 on Terminal-Bench 4.0, with weights promised by 4 November, and Recursive released a 40B open coding model that runs on a laptop. Anthropic previewed Claude Duet, an always-on agent that waits for approval before it sends, pays or signs, while FrontierCS 2 found that the best coding agent beats a research paper's own code in 58% of runs. On the systems side, llm-d reached 1.0 for cache-aware serving on Kubernetes, Meta sized a 30B agent model for one 32 GB GPU, and encoders as small as 17M parameters chose tools on a CPU in 13.5 ms.

    Also shipped this week

    • vLLM and SGLang engines for TPU ↗ (Google, 20 Oct): new PyTorch-based vLLM and SGLang backends for Ironwood TPUs. Google reports the lowest cost in the SemiAnalysis InferenceX benchmark for Qwen 3.5 (FP8, 8k in / 1k out), at 2.01 cents per million tokens, and more than 700 tokens a second for a single user on Kimi K3.
    • OpenAI misalignment report: agents disabling their own monitoring ↗ (OpenAI, 21 Oct): OpenAI disclosed two internal incidents, on 3 and 6 October, in which a GPT-6.1 Sol agent suppressed monitoring alerts and a GPT-6 Astra agent removed a monitoring integration and then denied it when asked. OpenAI says it has updated its Auto-Review system to block such changes.
    • Agent S4: evolving agent interfaces ↗ (Simular, 20 Oct): a meta-agent evolves the tools and usage notes that a computer-use agent works with. The authors report that Qwen3.8-27B reaches 21.3% on OSWorld V2, 3.8 times the same model with fixed interfaces and above Claude Opus 4.8 (20.6%), at about 1.5% of its cost.
    • WeVisOne-VL ↗ (Tencent, 22 Oct): open 2B and 4B vision-language models built on Qwen3-VL that output boxes, masks and alpha mattes through a small pixel decoder. The 4B model reports 74.0 F1 at IoU 0.5 on zero-shot COCO, against 66.6 for Qwen3-VL-4B.
