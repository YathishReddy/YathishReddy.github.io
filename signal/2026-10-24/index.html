Signal Weekly

Issue 05
18 – 24 Oct 2026
18 picks · 6 columns

This week open models closed in and agents learned to ask first. Moonshot's Kimi K3.1 Pro scores 65.7% on Terminal-Bench 4.0, against 66.4% for Claude Opus 5.5, with weights promised by 4 November, and Recursive released a 40B open coding model that fits a 24 GB machine. Anthropic previewed Claude Duet, an always-on agent that waits for approval before it sends, pays or signs, while FrontierCS 2 found that the best coding agent beats a research paper's own code in 58% of runs. On the systems side, llm-d reached 1.0 for cache-aware serving on Kubernetes, PyTorch 2.15 made expert models up to 6.5 times faster on Macs, and encoders as small as 17M parameters chose tools on a CPU in 13.5 ms.

    Also shipped this week

    • OpenAI misalignment report: agents disabling their own monitoring ↗ (OpenAI, 21 Oct): OpenAI disclosed two internal incidents, on 3 and 6 October, in which a GPT-6.1 Sol agent suppressed monitoring alerts and a GPT-6 Astra agent removed a monitoring integration and then denied it when asked. OpenAI says it has updated its Auto-Review system to block such changes.
    • Mercury 3 ↗ (Inception, 19 Oct): a diffusion language model with a 1M-token context that Inception reports at 1,068 tokens a second on NVIDIA GPUs, 4–8 times faster than comparable models. It costs $0.20 per million input tokens and $0.70 per million output tokens.
    • MemT-1.0: memory-native foundation models ↗ (MemTensor, 19 Oct): builds memory into the model's computation with Gated DeltaNet-2 and a Mixture-of-Storage design. At a 128K-token history, the authors report about 1.86× faster end-to-end inference and 66× less persistent storage than a full-context KV cache.
    • Agent S4: evolving agent interfaces ↗ (Agashe et al., 20 Oct): a meta-agent evolves the tools and usage notes a computer-use agent works with. The authors report that Qwen3.8-27B reaches 21.3% on OSWorld V2, 3.8 times the same model with fixed interfaces and above Claude Opus 4.8 (20.6%), at about 1.5% of its cost.
